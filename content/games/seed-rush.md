## 玩法說明

畫面分成上下兩半：

- **下半部（地底）**：芭樂會一直吐籽，你負責左右移動芭樂，讓種子穿過**倍數閘門**。種子越多越好。
- **上半部（戰場）**：種子會滑進漏斗、順著水管送到前線，變成**芭樂勇者的子彈**，自動射擊爬過來的蟲。

### 閘門

| 閘門 | 效果 |
| --- | --- |
| 黃綠色 **x2、x3** | 種子穿過後變成 2 倍、3 倍 |
| 藍色 **x5**（會左右移動） | 種子變成 5 倍，要看準時機 |
| 灰色 **上鎖閘門** | 這一波累積收集到指定數量的種子後解鎖，變成 x8 或 x10 的超強閘門 |
| 紅色 **÷2**（第 3 波開始出現） | 穿過的種子有一半會消失，記得避開 |

同一顆種子在同一個閘門只會倍增一次，但可以連續穿過好幾排閘門，**倍數會疊加**。

### 戰場

- 蟲頭上的數字是牠的血量，每顆種子子彈打掉 1 點。
- 勇者手上的子彈越多，**射速越快**。
- 蟲碰到勇者會扣一顆愛心，3 顆愛心用完就結束。
- 每 5 波會出現一隻**大 Boss**，血量很高，要先存好種子。
- 每一波結束後，閘門的位置和倍數都會重新排列。

## 開發筆記

### 靈感

這款的靈感來自手機上很常見的「倍數閘門」類小遊戲：東西往下掉，穿過不同倍數的閘門後數量暴增，再拿去打敵人。這類玩法看起來很爽，規則又一看就懂，所以我把它改成芭樂版本：主角是會吐籽的芭樂，子彈就是芭樂籽，敵人則是遊戲廳裡老朋友的「蟲」。

角色和美術全部是自己用像素畫的，玩法也做了調整，例如上鎖閘門要靠「這一波收集到的種子數」解鎖、加入會扣種子的 ÷2 陷阱。

### 直式畫面

前幾款遊戲都是橫式，這款因為是「由上往下掉」的玩法，改成 160 × 256 的直式畫面。網站的遊戲頁也加了一個 `portrait` 設定，直式遊戲會自動限制最大寬度，在電腦上不會被放大到超出螢幕。

### 怎麼判斷「穿過閘門」

每顆種子每一幀都會記錄上一幀的位置。只要「上一幀在閘門上方、這一幀在閘門下方」，而且水平位置落在閘門範圍內，就代表它剛好穿過閘門：

```js
if (s.py < g.y && s.y >= g.y && s.x >= g.x && s.x <= g.x + g.w) {
  // 穿過閘門
}
```

這樣不管種子掉得多快，都不會因為一幀移動太多而「跳過」閘門。

### 每個閘門只能倍增一次

如果不做限制，種子在閘門附近彈跳時可能重複觸發，數量會失控。所以每顆種子身上有一個 **bitmask**，每個閘門佔一個位元，穿過時把對應的位元設成 1，下次就不會再觸發。新分裂出來的種子會繼承同一個 bitmask，避免在同一個閘門裡無限複製。

### 效能：種子太多怎麼辦

倍數疊起來之後，種子數量很容易爆炸。畫面上同時最多只保留 220 顆種子，超過的部分會**直接送進水管**變成子彈。這樣既不會拖慢手機，玩家的收穫也不會因此減少。

### 漏斗和水管

漏斗是兩條斜線，種子碰到斜面就被「貼」在斜面上，往中間的開口滑。掉進開口後，種子會沿著一條預先定義好的水管路線（往下、往左、沿左牆往上）移動到勇者手上，才變成子彈。這段小小的延遲，讓玩家能清楚看到「我吐的種子正在送往前線」，畫面也更有連結感。

### 數值平衡

- 芭樂每秒吐 2.5 顆種子。
- 勇者的射速是「2 + 子彈庫存 ÷ 20」發／秒，最高 12 發，所以存越多打越快，存籽也有意義。
- 蟲要完整走進畫面一小段距離，勇者才會開火，子彈的飛行速度也放慢了，讓你看得清楚敵人長怎樣。
- 蟲的血量每波成長約 1.28 倍，速度也會慢慢變快；Boss 的血量是一般蟲的十幾倍。
- 測試時，只站在正中間不動的話，大概第 6 波就會撐不住；認真疊倍數的話，可以打到第 10 波的 Boss。

**2026-10-06 調整**：第一版吐籽太快、子彈太猛，蟲常常一進畫面就被秒殺，連長相都看不到。這一版把吐籽速度、射速和子彈速度都調慢，戰場才有來有往。
