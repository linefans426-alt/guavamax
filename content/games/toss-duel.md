## 玩法說明

兩隊隔著一道牆，輪流把東西丟向對方：**芭樂隊**丟芭樂，**可頌隊**（抱著小白狗的那位）丟可頌。先把對手的 100 點血量打到零的一方獲勝。

### 開始畫面

| 模式 | 說明 |
| --- | --- |
| 1P 玩芭樂隊 | 你在左邊，電腦控制可頌隊 |
| 1P 玩可頌隊 | 你在右邊，電腦控制芭樂隊 |
| 2P 對戰 | 兩個人用同一台手機或電腦輪流丟 |

### 怎麼丟

- **手機／滑鼠**：在畫面上按住，像拉彈弓一樣**往後拉**，拉的方向決定角度、拉的長度決定力道，放開就丟出去。拉的距離太短會取消。
- **鍵盤**：↑ ↓ 調整角度，**按住空白鍵**蓄力（力道條會來回跑），放開時的力道就是出手力道。
- 瞄準時只會顯示方向和力道，不會畫出完整的拋物線，要靠自己的手感。

### 風向

畫面上方中間是**風向**：五格代表風力，箭頭代表風往哪邊吹，4 級以上會變紅色。每一回合都會重新決定風向，雲也會跟著風飄，丟之前記得看一下。

### 傷害

- **直接砸中**對手：30 點傷害。
- 落在對手附近：依距離造成較少的傷害。
- 丟太近的話，**自己也會被波及**。
- 砸到中間的牆就沒了。

### 道具

每隊各有 4 個道具，**每個道具一場只能用一次**，在自己的回合丟出去之前按下就能使用（再按一次取消）。

| 按鈕 | 道具 | 效果 |
| --- | --- | --- |
| 雙 | 雙重投擲 | 這回合用同樣的角度和力道連丟兩顆 |
| 巨 | 巨大化 | 投擲物變大，傷害提高到 45、爆炸範圍也變大 |
| 無 | 無風 | 這一丟完全不受風影響 |
| 補 | 補血 | 立刻回復 25 HP（不用丟就生效，同回合還能再用一個道具） |

## 開發筆記

### 靈感

這款的靈感來自很多人小時候玩過的 Flash 隔牆投擲對戰：兩邊各站一個角色，中間一道牆，輪流算風向、抓力道丟東西。規則很單純，但「差一點就中」的感覺很讓人上癮，很適合做成網頁小遊戲。

兩位主角是我依照兩張 Q 版人物圖，自己用 16 × 21 的像素重新畫的：一位是刺蝟頭、穿深藍背心和綠短褲的男生；另一位是黑長髮、戴金框眼鏡、穿可頌圖案襯衫，手上抱著一隻小白狗的女生。可頌隊丟可頌，就是從她襯衫上的圖案來的。

### 物理：重力加上風

投擲物每一幀只做四件事：

```js
p.vx += wind * WIND_K * dt; // 風只影響水平速度
p.vy += GRAV * dt;          // 重力只影響垂直速度
p.x += p.vx * dt;
p.y += p.vy * dt;
```

風就是一個固定的水平加速度。逆風丟要多給力道或拉高角度，順風則要收一點。為了不讓高速的投擲物「穿過」牆或角色，每一幀會拆成兩個小步驟來檢查碰撞。

### 彈弓式瞄準

手機上沒有鍵盤，所以改成拉彈弓：記下按下去的位置，拖曳時計算「起點 − 目前位置」的向量，用 `Math.atan2` 算出角度，向量長度除以 52 px 就是力道百分比。右邊的可頌隊面向左邊，所以水平方向會乘上 −1，兩隊就能共用同一套程式。

### 電腦怎麼瞄準

電腦用的物理函式跟遊戲完全一樣。輪到它的時候，會把角度 20°～80°、力道 30%～100% 的組合全部「在腦中」模擬一次（大約兩千多組），找出落點最接近對手的那一組。

但如果直接照答案丟，它會百發百中，一點都不好玩。所以我在角度和力道上加了隨機誤差，而且**誤差會隨著丟的次數慢慢縮小**，就像真人在修正手感：前幾顆常常打偏，越打越準。電腦也會用道具，例如血量低時補血、風很大時開無風、對手快沒血時用巨大化收尾。

### 數值調整

一開始讓「砸中身體」也依照離身體中心的距離算傷害，結果砸到頭頂只扣十幾點，電腦對電腦要打四十幾回合才分出勝負。後來改成**直接命中拿滿傷害**，再寫一個電腦對電腦的模擬程式跑了二十場，一場平均大約十回合結束，節奏剛好。
