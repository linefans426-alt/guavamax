## 玩法說明

毛毛狗會自己一直往前跑，你只要決定牠走**上面**還是**下面**那條路。

- **手機**：點畫面的上半部或下半部就會換路，也可以按住上下拖。
- **鍵盤**：↑ ↓（或 W S）換路。

狗狗頭上的數字就是牠的**戰力**，目標是讓數字越滾越大、跑得越遠越好。

### 卡片

路上會出現兩張一組的卡片，你走哪條路就吃到哪一張：

| 卡片 | 效果 |
| --- | --- |
| 骨頭 **+數字** | 戰力加上這個數字 |
| 球 **x2、x3** | 戰力直接變成 2 倍、3 倍 |
| 愛心 **+1** | 回復一顆愛心（少血時才會出現） |
| 便便 **−數字** | 戰力被扣掉 |
| 洗澡 **÷2** | 戰力砍半（狗狗最討厭洗澡了） |

### 怪物

怪物頭上也有數字，而且會用顏色提醒你：

- **綠色**：比你小，撞上去就能打倒牠，還會把牠的數字**加到你身上**。
- **紅色**：比你大，撞上去會被打回來、扣一顆愛心，記得換到另一條路閃開。

| 怪物 | 特色 |
| --- | --- |
| 野貓 | 最常見的怪物 |
| 松鼠 | 一跳一跳地衝過來 |
| 烏鴉 | 跑超過 30 公尺後出現，會在空中飛 |

有時候兩條路都打得過，選數字大的那邊可以吃得比較多；有時候同一條路會連續來兩隻，要先吃掉第一隻、數字變大之後才打得贏第二隻；跑遠一點還會出現「一邊是強怪、一邊是壞卡片」的陷阱，只能選比較不痛的那邊。

### Boss

大約每 110 公尺會出現 Boss（**吸塵器大魔王**、**吹風機怪獸**輪流出場），兩條路都擋住，一定要正面對決。Boss 出場前會先送一組卡片，選對才打得贏。打倒 Boss 會回復一顆愛心。

### 汪汪技能

每打倒一隻怪物，下方的**汪汪能量**就會增加一格，集滿 8 格後點右下角的「**汪！**」按鈕（或按空白鍵），狗狗會大叫一聲，畫面上所有怪物被嚇到、**數字直接減半**。留給打不贏的 Boss 用最划算。

3 顆愛心都用完就結束，看看你能跑幾公尺！

## 開發筆記

### 靈感

這款的靈感來自手機上很常見的一種廣告遊戲：角色自動往前跑，在兩條路之間選卡片，讓頭上的數字越滾越大，再拿去跟怪物比大小。規則幾秒鐘就看得懂，數字從個位數一路滾到幾億的感覺又很爽，很適合做成網頁小遊戲。

主角是我家的白色毛毛狗，依照牠的照片自己用 20 × 14 的像素重新畫：白色蓬蓬的毛、黑豆豆眼和黑鼻子，還有粉紅色的腮紅。卡片也都用狗狗的日常來設計：骨頭和球是好東西，便便和洗澡是壞東西，Boss 則是每隻狗都討厭的吸塵器和吹風機。

### 怪物的數字要跟誰比？

一開始，怪物的數字是照「狗狗現在的數字」去產生的。結果發現不管你選對選錯，下一波怪物都會跟著你一起變大或變小，**選錯完全沒有後果**。寫了一個會選最佳路線的機器人來測試，它可以一直跑下去、永遠不會死。

後來改成另外記一個「**預期戰力**」：每經過一段卡片或怪物，就假設一個正常玩家的戰力會成長多少，怪物的數字照預期戰力來產生。

```js
if (isCards) expect *= 1 + 0.45 * creep;
else expect *= 1 + 0.36 * creep;   // creep 會隨著距離慢慢變大
```

這樣一來，吃到便便或洗澡掉下來的數字會一直影響後面；反過來，一直選對、比預期還強的話，後面的怪物就會一片綠色，打起來很爽。`creep` 讓預期戰力越跑越快成長，所以就算一直選對，最後還是會被追上。

### 測試結果

| 玩法 | 平均能跑多遠 |
| --- | --- |
| 亂按的機器人 | 大約 100～300 公尺 |
| 每次都選最佳路線的機器人 | 大約 600～1300 公尺 |

真人玩家的反應比機器人慢，又要一邊看數字一邊做決定，能跑到 500 公尺以上就很厲害了。

### 大數字怎麼顯示

數字是用乘法在成長的，跑遠一點很容易超過一兆。畫面很小，所以超過一萬就改用縮寫：K（千）、M（百萬）、B（十億）、T（兆），再大就用放置型遊戲常見的 aa、ab、ac… 繼續往下排。
